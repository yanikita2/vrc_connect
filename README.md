# vrc_connect

Runtime configuration for VRChat integrations.

Endpoint: https://yanikita2.github.io/vrc_connect/config/runtime.json

Configuration values use stable identifiers understood by the consuming client. This repository contains public runtime data only.

Run `python validate.py` before publishing changes and increment the manifest revision.

Cross-world collectible card data is separate: see [keys/README.md](keys/README.md).
Adding key data does not change the runtime configuration revision.
